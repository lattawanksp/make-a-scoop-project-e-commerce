# Make A Scoop

Make A Scoop is a small e-commerce landing page for a creative ice cream brand.

This project shows a new ice cream collection with a strong visual style. It includes a hero section, product cards, a brand story section, a process section, and a newsletter form.

## Demo Idea

The page presents the `GENESIS` collection for `Q2 2026`. The design uses dark colors, bold display text, and product images to create a modern brand feeling.

## Built With

- HTML5
- CSS3
- Google Fonts

## Main Features

- Fixed navigation bar
- Full-screen hero section
- Product collection cards
- Brand story and process sections
- Newsletter sign-up form
- Mobile responsive layout

## Project Structure

```text
make-a-scoop-project-e-commerce/
|-- index.html
|-- style.css
|-- src/
|-- wireframe.excalidraw
```

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in your browser.

You do not need to install any package for this project.

## Notes

- Images are stored in the `src` folder.
- The page is a front-end UI project only.
- The cart button and newsletter form are not connected to a real backend yet.
